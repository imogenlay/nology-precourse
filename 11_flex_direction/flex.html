My understanding of this challenge was to have the cards ordered sequentially in the HTML file but to have the order changed by CSS only.

So, in the HTML file they go 1, 2, 3, 4, 5, 6, 7, 8, but are reversed below.
This was done using 3 flex boxes. The main element is a flex box with a black outline. Everything is centered and the flex-direction is column.
There are then two divs: one for the four horizontal cards, and one for the four vertical cards.
The horizontal cards use row-reverse, vertical use column-reverse. The order of two groups are then set to 1 and 2 so that the horizontal cards appear before the vertical cards.
